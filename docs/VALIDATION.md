## Reproduce performance measurements

```bash
python scripts/benchmark.py --jobs 10 --recipients 100 --concurrency 4
```

The script starts isolated real API and worker processes on localhost, generates actual PDFs, verifies every job succeeds, and measures end-to-end time. It cleans up its temporary data and child processes. The workload submits 10 jobs of 100 recipients with four concurrent clients and one worker.

Results are machine- and workload-specific. A small local run is not an SLA, a distributed-system benchmark, or proof of production capacity. Submission latency includes validation, persistence, and HTTP overhead; completion time also includes queueing and PDF generation. Reported p95 is interpolated across the measured samples.
